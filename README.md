## 玩法（参考公开票样）

> 刮开覆盖膜，如果刮出「**喜**」图符，即可获得该图符下方所对应的奖金；如果刮出「**囍**」图符，即可获得该图符下方所对应奖金的**两倍**。中奖奖金兼中兼得。

票面下方印着金额，覆盖膜刮开后才露出「喜 / 囍 / 空」，因此金额可见、结果未知——与常见实体刮刮乐一致。

**50 元票为双玩法区**：

- 玩法区：10 行 5 列，共 50 次机会，规则同上（喜=奖金、囍=两倍）；
- 好运区（顶部 1 行 5 列）：五个单元**未刮开前均为「喜」字膜**；刮开后，未中奖单元显示祝福文字

## 整本玩法（“本”配额）

以「本」为组织单位（对玩家可见的只有这些）：

- **先付款，后取票**：进入页面不自动发牌，显示空状态；上方**票架**展示当前本剩余的全部奖券（抽一张少一张、已刮结算的置灰），点击架上一张（或「抽一张」随机）付费抽取（每次扣体验金），才能得到一张奖券。
- **未刮开的奖券可免费更换**：点击票架中另一张未刮的票，手中这张即放回架中（不重复扣费）；「抽一张」按钮只在空手时可用，手持奖券时每人仅能持有一张。
- 持票可「**一键刮开**」（部分刮开时按钮变为“刮开剩余并结算”）；全部玩法区刮开后自动结算（50 元票需刮完玩法区与好运区）。
- 部分刮开想换新票：需先「**放弃**」——已刮开格子的奖金立即结算，未刮开区域不再兑奖。
- **体验金不足时**：「抽一张 / 换一本」等操作均禁用，需先「领取体验金」。
- 点「**换一本**」作废当前本剩余奖券并重新开一本；已刮开且结算的张数与中奖自动计入战绩。
- 一本全部刮开后给出整本结算（只展示累计中奖，不展示内部配额）。

**单本具体配额不向玩家公开**（不显示在票面、本栏或弹窗），避免泄露整本奖池。

整本生成口径（面向开发者/运营）：

0. **每面额各自缓存最后一「本」**：四个面额分别在本地各自保存当前那一本（含手牌与已刮进度），切换票面时直接回到对应那本、不会重新生成；只有点「换一本」才为当前面额新开一本。
1. 每本取随机**内部配额 G → 返奖率 R = G ÷ 一本总价**，满足三条宏观/微观约束：
   - **保底**：R 恒 ≥ 50%（任何一本都不会低于半额）；
   - **宏观**：大基数下 E[R] = 65%（卖家约留存 35% 收益），由右尾缩放系数精确折算；
   - **微观**：R 带右尾，约 5% 的本返奖超过 100%（个别买家整本赚钱），并以官方头奖中奖面（每百万张 counts[0] 张）让极稀有的本开出满额大奖；
2. 把 G 按**现有标准奖级的相对权重**拆成 M 注（M 由官方平均单注奖金推导且不超过一本张数）：
   逐注从表内金额中按官方权重配额抽取，每注 ≥ 面值并为尾注预留，使 **Σ注额 = G** 精确成立；
   由官方平均单注奖金推导注数，本内中奖面自然收敛到官方的 **31.91%**；
3. 注随机落到编号连续的一本中（票号顺序不变、中奖位置乱序），其余票为未中奖票；
4. 中奖票把注额按表内金额拆成 1~3 个刮开区；「囷」格的印制值为该格金额的一半（兑奖按该图符下方奖金两倍，与印制自洽）；
   50 元票的注额还可能落到顶部好运区（刮出金额即中奖，不翻倍）；含满额大奖的本由头奖独占一注、其余配额拆到剩余票上；
5. 整本实付总额 = G，恒 ≥ 一本总价 × 50%，结构上天然合格；配额异常时才触发整本重生成（防御分支，最多 24 次）。

## 中奖率
- 公开的行业参数参考：返奖率约 **65%**、中奖面约 **31.91%**、各票种奖级数与中奖机会次数。
- 官方 50 元面值为双玩法区（55 次机会），本演示**未收录官方设奖**：50 元票奖级为按同一口径（31.91% / 65%）构造的**演示设奖**，
  好运区规则（吉祥 / 快乐 / 如意 / 幸运 / 平安，刮出金额即中奖）为演示设定，已在票面、奖级页与页脚注明。

## 概率模型
中奖注数按每 **1,000,000 张**设奖池，联立两个约束反推各奖级中奖张数：

```
Σ counts           = 中奖面 × 1,000,000        = 319,100
Σ (counts × prize) = 面值 × 1,000,000 × 65%    = 面值 × 650,000
```

高奖级按同系列常见设奖结构给定，最低两档由方程精确求解，因此：

- 中奖面恒等于 **31.91%**
- 返奖金额恒等于 **65%**（10 元票每百万张 650 万、20 元票 1,300 万、30 元票 1,950 万、50 元票 3,250 万）

生成一张票时：先按中奖面判定是否中奖 → 按奖级权重抽出该张票的总奖金 → 将总奖金拆到 1~3 个刮开区（随机使用「喜」或「囍」，囍的实得金额为印制金额的两倍），其余刮开区为空白并随机印制小额金额。

页面「概率验证」面板提供两组模拟：

- **整本口径模拟**：按整本配额流程跑 N 本，输出：整本保底达标率（每本 ≥ 50%）、**平均一本返奖率**（理论 65%）、中位数返奖率、返奖超 100% 的本占比、最高单本返奖率、单张中奖面（本内实际有奖张占比，≈ 31.91%）。由于分布带重尾（含满额大奖本），平均返奖率需较大基数才稳定收敛到 65%。
- **单张概率模拟**：按官方口径直接抽 1 万 / 10 万 / 100 万张，核对中奖面与返奖率是否收敛到 31.91% / 65%。

> 口径说明：整本玩法以“本”为单位派奖（每本返奖 ≥ 50% 保底、整体平均 ≈ 65%，单本允许上下浮动，约 5% 的本可超 100%），单张官方口径（31.91% / 65%）作为奖级结构的参考口径单独模拟；「囷」双倍按票面规则计为实得。
> 概率提升彩蛋（仅演示）：连续点按票面说明文字 6 次可切换「中奖概率提升」开关（一等奖/二等奖概率显著提高），再次连点 6 次恢复。原「重置」按钮已移除（体验金与战绩可在“我的战绩”中清空）。
> 由于最高奖级极稀有，单张模拟在小样本（1 万 / 10 万张）下返奖率会因是否开出头奖而明显波动，抽到 100 万张时最稳。

# 囍相逢· 刮刮乐（玩法 / 奖级 / 概率演示）

「囍相逢」是一款**独立原创的网页刮刮乐演示**，玩法规则与票面结构参考公开票样资料实现，纯前端静态页面，无依赖、无构建，可直接用浏览器打开或托管到 GitHub Pages。

- 本地预览：`python3 -m http.server 8088` 后访问 http://127.0.0.1:8088

## 玩法（参考公开票样）

> 刮开覆盖膜，如果刮出「**喜**」图符，即可获得该图符下方所对应的奖金；如果刮出「**囍**」图符，即可获得该图符下方所对应奖金的**两倍**。中奖奖金兼中兼得。

票面下方印着金额，覆盖膜刮开后才露出「喜 / 囍 / 空」，因此金额可见、结果未知——与常见实体刮刮乐一致。

## 中奖率
- 公开的行业参数参考：返奖率约 **65%**、中奖面约 **31.91%**、各票种奖级数与中奖机会次数。
- 面值有10、20、30 （50 元面值双玩法区 / 55 次机会 未纳入本演示）

## 概率模型
中奖注数按每 **1,000,000 张**设奖池，联立两个约束反推各奖级中奖张数：

```
Σ counts           = 中奖面 × 1,000,000        = 319,100
Σ (counts × prize) = 面值 × 1,000,000 × 65%    = 面值 × 650,000
```

高奖级按同系列常见设奖结构给定，最低两档由方程精确求解，因此：

- 中奖面恒等于 **31.91%**
- 返奖金额恒等于 **65%**（10 元票每百万张 650 万、20 元票 1,300 万、30 元票 1,950 万）

生成一张票时：先按中奖面判定是否中奖 → 按奖级权重抽出该张票的总奖金 → 将总奖金拆到 1~3 个刮开区（随机使用「喜」或「囍」，囍的实得金额为印制金额的两倍），其余刮开区为空白并随机印制小额金额。因此整张票的实得奖金严格等于所中奖级金额，且「兼中兼得」。

页面「概率验证」面板可一键模拟 1 万 / 10 万 / 100 万张，核对实际中奖面与返奖率是否收敛到理论值。

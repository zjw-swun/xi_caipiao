## 整本玩法（“本”配额）

以「本」为组织单位（对玩家可见的只有这些）：

- **先付款，后取票**：进入页面不自动发牌，显示空状态；上方**票架**展示当前本剩余的全部奖券（抽一张少一张、已刮结算的置灰），点击架上一张（或「抽一张」随机）付费抽取（每次扣体验金），才能得到一张奖券。
- **未刮开的奖券可免费更换**：点击票架中另一张未刮的票，手中这张即放回架中（不重复扣费）；「抽一张」按钮只在空手时可用，手持奖券时每人仅能持有一张。
- 持票可「**一键刮开**」（部分刮开时按钮变为“刮开剩余并结算”）；全部玩法区刮开后自动结算。
- 部分刮开想换新票：需先「**放弃**」——已刮开格子的奖金立即结算，未刮开区域不再兑奖。
- **体验金不足时**：「抽一张 / 换一本」等操作均禁用，需先「领取体验金」。
- 点「**换一本**」作废当前本剩余奖券并重新开一本；已刮开且结算的张数与中奖自动计入战绩。
- 一本全部刮开后给出整本结算（只展示累计中奖，不展示内部配额）。

**单本具体配额不向玩家公开**（不显示在票面、本栏或弹窗），避免泄露整本奖池。

整本生成口径（面向开发者/运营）：

1. 每本取随机**内部配额 G**（保底区间内随机整数、向下取整到 10 元），G 即该本实付奖金总额：约为一本总价的 30%~48%，**平均约 40%**；
2. 把 G 按**现有标准奖级的相对权重**拆成 M 注：M ≈ G ÷ 官方平均单注奖金，逐注从表内金额中按官方权重配额抽取，每注 ≥ 面值并为尾注预留，使 **Σ注额 = G** 精确成立；
3. 注随机落到编号连续的一本中（票号顺序不变、中奖位置乱序），其余票为未中奖票；
4. 中奖票把注额按表内金额拆成 1~3 个刮开区；「囷」格的印制值为该格金额的一半（兑奖按该图符下方奖金两倍，与印制自洽）；
5. 整本实付总额 = G，恒 ≥ G × 90%，结构上天然合格；配额异常时才触发整本重生成（防御分支，最多 24 次）。

## 中奖率
- 公开的行业参数参考：返奖率约 **65%**、中奖面约 **31.91%**、各票种奖级数与中奖机会次数。
- 官方 50 元面值为双玩法区（55 次机会），本演示**未收录官方设奖**：50 元票为按同一口径（31.91% / 65%）构造的**演示设奖**，已在票面、奖级页与页脚注明。

## 概率模型
中奖注数按每 **1,000,000 张**设奖池，联立两个约束反推各奖级中奖张数：

```
Σ counts           = 中奖面 × 1,000,000        = 319,100
Σ (counts × prize) = 面值 × 1,000,000 × 65%    = 面值 × 650,000
```

高奖级按同系列常见设奖结构给定，最低两档由方程精确求解，因此：

- 中奖面恒等于 **31.91%**
- 返奖金额恒等于 **65%**（10 元票每百万张 650 万、20 元票 1,300 万、30 元票 1,950 万、50 元票 3,250 万）

生成一张票时：先按中奖面判定是否中奖 → 按奖级权重抽出该张票的总奖金 → 将总奖金拆到 1~3 个刮开区（随机使用「喜」或「囍」，囍的实得金额为印制金额的两倍），其余刮开区为空白并随机印制小额金额。

页面「概率验证」面板提供两组模拟：

- **整本口径模拟**：按整本配额流程跑 N 本，输出整本合格率、平均一本中奖额、**平均一本返奖率**（实付口径，均值约为一本总价 40%）与**单张中奖面**（本内实际有奖张占比，由现有奖级结构自然推出，约 18%~25%）；
- **单张概率模拟**：按官方口径直接抽 1 万 / 10 万 / 100 万张，核对中奖面与返奖率是否收敛到 31.91% / 65%。

> 口径说明：整本玩法以“本”为单位派奖（平均一本返奖 ≈ 40%，单本允许上下浮动），单张官方口径（31.91% / 65%）作为奖级结构的参考口径单独模拟；「囷」双倍按票面规则计为实得。
